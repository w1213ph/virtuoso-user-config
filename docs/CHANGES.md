## 试过但撤回或未启用

- 全局表单 label=14/text=15：实际 Direct Plot 出现文字、单选项和边框重叠，撤回为 11/11。
- 全局 `QT_SCALE_FACTOR=1.2`：原理图底部绘图范围被裁切，撤回。旧终端继承变量的问题改用可选启动脚本说明，不自动修改全局 shell。
- 初期把工作点固定为 `opPoint` 的全局默认规则：无法正常恢复参数显示，已由双文件和菜单后处理替代。
- 保存后撤销 `dbUndoAcrossSave`：无界面行为测试不足，未启用。显示 Undo/Redo History 不等于此功能。
- Maestro plotting template：缺少具体测试/信号，没有创建通用模板。
- 文章中的自定义快捷键、作者路径、固定窗口位置和不明确的自动保存设置：没有应用。
